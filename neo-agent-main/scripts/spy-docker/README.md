# 스파이 `docker` 하네스

테스트 스위트가 **실제로 `docker`를 부르는지**를 관측으로 확인하는 도구다. 주장("주입했으니 안 부른다")과 관측("호출 로그가 0줄이다")은 다른 것이고, 여기 있는 것은 후자를 만드는 수단이다.

## 왜 있는가

`packages/cli`의 테스트는 `startCli`를 부를 때마다 `probeDocker`를 명시 주입한다(`packages/cli/test/probe-docker.ts`). 주입을 잊으면 시작 시퀀스 5b가 **실제 `docker version` 프로세스를 스폰**하고, 그러면 게이트의 결과가 테스트 머신의 Docker 설치·데몬 상태·권한에 좌우된다. 문제는 그 실패가 **테스트가 통과하는 동안에는 보이지 않는다**는 것이다 — 느려질 뿐이다.

2026-08-09 T-014가 이 방법을 손으로 한 번 만들어 쓰고 버렸고, 버렸기 때문에 이후 9사이클 동안 "되살리기"가 이월 항목으로 남았다. 그래서 레포에 둔다.

## 쓰는 법

```sh
cd neo-agent-main
: > /tmp/spy.log     # 먼저 만든다 — 없는 파일과 0줄인 파일을 구분해야 한다
PATH="$PWD/scripts/spy-docker:$PATH" NEO_SPY_LOG=/tmp/spy.log pnpm test
wc -l < /tmp/spy.log     # 0이어야 한다
```

파일을 미리 만드는 것이 절차의 일부다. 안 만들면 호출이 0회일 때 파일 자체가 없어 `wc`가 에러를 내고, **에러와 "0건"이 구분되지 않는다** — 관측 도구가 자기 결함을 관측 대상의 성질로 보이게 하는 형태다(2026-08-09 devnote §13.9와 같은 계열).

실측 (2026-08-10, 이 레포): 호출 **0줄**, 통과 **2,047건**으로 하네스 없이 돌린 것과 동일.

로그 경로는 `NEO_SPY_LOG`로 정한다(기본 `/tmp/neo-spy-docker.log`). 한 줄이 한 호출이며 시각·pid·인자가 남는다.

## 종료 코드가 1인 것은 설계다

0을 돌려주면 호출한 쪽이 "docker가 있고 정상"으로 읽어 다른 경로를 타고, 그 순간 이 하네스는 **관측 도구가 아니라 동작을 바꾸는 개입**이 된다. 비영으로 두면 `probeDocker`의 계약(부재·권한 없음·무응답을 전부 판정으로 흡수 — `docs/SANDBOX.md` §3)이 그대로 작동해 불가용 갈래로 떨어진다.

따라서 **하네스가 있든 없든 스위트의 통과 수가 같아야 한다.** 달라지면 하네스가 아니라 스위트가 docker에 의존하고 있다는 뜻이고, 그것이 이 도구가 찾는 바로 그 상태다.

## 게이트가 이것을 부르지 않는 이유

`pnpm check`에 넣으면 실제 스폰을 잡으므로 구멍이 없다. 하지만 게이트가 **PATH 조작에 의존**하기 시작하면 게이트 자신의 재현성이 셸 구성에 종속된다. 그래서 2026-08-10 판정 D-1은 역할을 갈랐다:

- **강제** — `scripts/check-core-budget.mjs`의 정적 검사. 판정 대상은 **"주입했는가"**이지 "어느 파일을 임포트했는가"가 아니다: 공용 헬퍼(`packages/cli/test/probe-docker.ts`)를 들여도 되고, 그 헬퍼에 의존하지 않아야 할 이유가 있으면 자체 스텁을 `factories.probeDocker`에 넣어도 된다(`distribution-qa-b.contract.test.ts`가 그렇다 — 독립 검증이라 다른 작성자의 하네스를 일부러 쓰지 않는다). `pnpm check`가 매번 돌린다.
- **관측** — 이 하네스. 정적 검사가 못 잡는 것이 의심될 때 손으로 돌린다. **무엇을 못 잡는지의 목록은 `docs/SANDBOX.md` §3이 정본이고 여기 옮겨 적지 않는다** — 2026-08-10 독립 검증(F-V4)이 이 줄의 예시가 낡아(그 사이 일부가 닫혔다) 게이트를 실제보다 약하게 말하는 것을 잡았다. 예시를 적는 순간 §3이 바뀔 때마다 여기가 낡는다.

둘은 경쟁안이 아니라 서로를 보완한다. 정적 검사는 "잊었는가"를 막고, 하네스는 "정말 0회인가"를 잰다.
